# Orquesta Programacion Web Local

Usa esta skill para UI, HTML, frontend, paneles o artefactos web.

## Reglas

- Probar en local antes de subir.
- Mantener estilo existente de la app.
- Todo texto visible debe ser i18n cuando el proyecto lo requiera.
- No hardcodear configuracion que deba cambiar sin redeploy.
- No crear landing si el usuario pidio una herramienta/app real.

## Validacion

- Capturas desktop y movil.
- Revisar solapes, tablas, cards, botones, textos largos y estados vacios.
- Verificar assets cargados, peso razonable y rutas relativas.
- Si hay canvas/3D, comprobar que no esta en blanco.

## Entrega

URL local, capturas o rutas, fallos encontrados y cambios aplicados.
