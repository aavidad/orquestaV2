# orquesta-capacity

Responsabilidad: seleccion dinamica de capacidad.

Incluye:

- pools;
- modelos;
- reasoning;
- perfiles de tarea;
- cuota;
- presupuesto;
- escalado;
- degradado;
- handoff preventivo;
- scores por perfil.

No asigna trabajo por rol fijo. Decide por fase, riesgo, calidad, coste, cuota y evidencia.
