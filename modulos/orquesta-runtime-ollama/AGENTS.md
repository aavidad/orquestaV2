# Contexto local: orquesta-runtime-ollama

Adaptador HTTP opt-in para gestionar modelos Ollama locales, remotos o cloud
desde el puerto neutral de runtime.

Reglas:

- No metas Ollama en core, workflow, domain-work ni Director Operativo.
- No metas reglas OPES aqui. Este modulo solo traduce gestion de modelos.
- No proyectes tokens, HOME reales ni rutas locales en respuestas, logs o
  evidencia.
- No anadas rails de calidad, palabras o capacidad. Si Ollama acepta una forma,
  el adaptador la transporta; si falta un campo imprescindible, devuelve error
  tecnico normal.
