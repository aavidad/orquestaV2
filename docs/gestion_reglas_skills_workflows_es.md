# Gestión de Reglas, Skills y Workflows Editables

A medida que Orquesta asume el rol de orquestador universal del workspace, todas las normativas e instrucciones que gobiernan a los agentes operan desde el núcleo persistente de manera dinámica.

- **Alta y Asignación Flexible:** Las directrices (reglas, workflows, skills) pueden determinarse a nivel **global**, restringirse a un **Proyecto** en particular, o asociarse a un **Rol** y **Agente** singular (como los roles de documentador vs programador).
- **Control Omnicanal (Web/API/CLI):** Es posible alterar, añadir o deshabilitar cualquier directiva sobre la marcha mediante los adaptadores de entrada (Web, API JSON, CLI). Se persigue modificar el comportamiento del supervisor en vivo sin requerir detención.
- **Trazabilidad Estricta:** Las iteraciones sobre estas reglas no destruyen historial. Cualquier mutación será preservada o versionable para mantener la trazabilidad de por qué las decisiones de los agentes cambian con el tiempo.
