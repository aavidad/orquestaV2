# Editable Rules, Skills and Workflows Management

As Orquesta takes on the role of universal workspace orchestrator, all directives and instructions governing the agents operate dynamically right from the persistent core.

- **Flexible Creation and Assignment:** Guidelines (rules, workflows, skills) can be set at a **global** level, restricted to a specific **Project**, or linked to a specific **Role** and **Agent** (e.g. documenter vs programmer mappings).
- **Omnichannel Control (Web/API/CLI):** It is fully supported to alter, append or disable any directive on-the-fly via any of the inbound adapters (Web, JSON API, CLI). The goal is to modify supervisor behavior live, without hard stoppages.
- **Strict Traceability:** Iterations regarding these rules never destroy logs. Any mutation will be preserved or versioned to keep traceability of why agent decisions evolve over time.
